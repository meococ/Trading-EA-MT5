## Additional zero-cost external screen

The bounded external pass excluded every source class already sealed by the
workspace and allowed only primary-documentation review. Grok returned
`NO_NEW_FREE_PIT_SOURCE`; Lead verification confirms the controlling failures
for its three closest objects:

1. Eurostat's API is free and updates twice daily, but Eurostat explicitly
   states that the database always contains the latest version and has no
   versioning or documentation of past versions. It cannot reconstruct a PIT
   first-public tape.
2. The U.S. Treasury XML feed exposes daily interest-rate history (including
   the par curve from 1990). It is a daily market-rate/price object, not a new
   signed non-price M5/M15 shock, and maps back to the sealed rates/lead-lag
   family.
3. DOL/ETA does provide archived weekly UI-claims releases and an explicit
   Thursday 08:30 EST publication schedule. Selecting claims is still the
   already-closed scheduled-macro family; a signed surprise needs a PIT
   expectation source that this feed does not provide.
