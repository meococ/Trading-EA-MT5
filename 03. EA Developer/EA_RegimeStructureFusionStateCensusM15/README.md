# EA_RegimeStructureFusionStateCensusM15

Research-only, zero-trade M15 census for the five RSF indicators. The wrapper
maps the canonical M5 period token to M15 only while including the byte-bound
base engine; the production EA source is not modified. It rejects every entry,
sequence and path-management route and exports only closed-bar state.

This package exists because M15 indicator state cannot be reconstructed by
resampling M5 outputs. HYP-015 through HYP-018 tested simultaneous state,
first-hit barriers, MBB events and TB structural events. All four were terminal
economic kills; 2023+ remained sealed. See
`04. Memory/research/20260808_FIVE_INDICATOR_NATIVE_CENSUS_CLOSEOUT.md`.

It has no optimization, validation, holdout, paper/live or economic authority.
