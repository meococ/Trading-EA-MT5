# SF02 / Q1 — AUTOPSY PLAN (pre-registered)

Frozen before any computation. This document enumerates EVERY metric,
slice and bin edge to be computed. Anything computed outside this plan
is labelled "unplanned" in AUTOPSY.md. All inputs are DESIGN bars only;
referee path = `pa_eval.evaluate`; metrics computed outside the referee
are labelled DESCRIPTIVE.

## Population (fixed)

- Families: F1..F6 as screened in SF01, corrected tags (tag = entry
  index). "Thick cell" per family = the screened config with the
  largest signal count:
  - F1: `S=18, gen=line1_cluster, rej_body=0`
  - F2: `S=18, gen=line1_cluster, rej_body=0`
  - F3: `S=18, gen=line1_cluster, rej_body=0`
  - F4: `S=18, gen=line1_cluster, tr_src=h1`
  - F5: `S=14, tr_src=h1, tol_atr=1.0`
  - F6: `S=24, gen=line1_cluster, box_atr=4.0`
- Entries regenerated by `mod.detect(D, c_rt, params)` on the same
  caches — deterministic, identical to the screened sets.
- Matched randoms: `pa_random.match_random(sig_list, bars, K=20,
  seed=20260920)` — identical seed and contract to the screens.

## A1 — Random drag curve (REFEREE path, ledgered)

- Anchor signal set: pooled, deduplicated in-session signal bars of
  the six thick cells above, per symbol.
- Random entries: `match_random` on that anchor set, K=20,
  seed=20260920; these picks are fed to `pa_eval.evaluate` as the
  strategy-side entries (`random_enabled=False`) so every fill is the
  referee engine's.
- Grid (32 configs): `S_pips in {11,14,18,24,32,40,55,75}` x
  `tp_mult in {1, 1.5, 2, 3}`; all 4 symbols per call; cost tier x1
  only (exit mix and fill path are tier-invariant; x2 drag noted
  qualitatively).
- Engine keys: order_type=stop, v_bars=3, invalidation=True,
  session_cancel=True, flats standard, weekend_veto — identical to
  the SF01 screens.
- Metrics per config: exp_R, PF, N, WR, exit mix
  (SL/TP/DAILY/FRIDAY/MIDNIGHT/DATA_END shares), per-symbol exp_R/PF.
- Questions: (a) at which (S,tp_mult) does random exp_R exceed
  -0.03 R? (b) TP-reach share vs S — how much do DAILY/FRIDAY/MIDNIGHT
  exits eat as S grows?

## A2 — Entry information, exit-free (DESCRIPTIVE)

- For each thick cell's entries and its matched randoms (K=20):
  forward M5 path from the signal bar close; horizons
  h in {6, 12, 24, 48, 96} bars, capped at `next_end[sig]` (session/day
  flat) and at data end.
- MFE = max over the window of `side*(h[i]-entry_px)` in ATR(H1) units;
  MAE = max of `-side*(l[i]-entry_px)` (adverse). `entry_px` =
  `order_px` (stop level — the causal fill reference).
- Metrics: E[MFE], E[MAE], edge ratio E[MFE]/E[MAE]; delta vs the same
  statistic on matched randoms; 95% CI on the delta from a
  day-clustered bootstrap (B=1000, cluster = UTC day of signal bar).

## A3 — Perception audit (DESCRIPTIVE; salience defined a priori)

- Zone density per generator (line1_cluster, sd_base): mean count of
  armed zones within +-1xATR(H1) and +-2xATR(H1) of close, per bar,
  pooled over DESIGN.
- Rank of each signal's triggering zone by `strength` among armed
  zones at t.
- SALIENCE score (causal, fixed weights, declared before looking):

      salience = 1.0 * touches_respected     # n_respected field
               + 1.0 * pivot_conf            # 1 if a confirmed H1/H4
                                             # pivot is within
                                             # 0.5*ATR_H1 of the zone
                                             # edge, else 0
               + 0.5 * round_conf            # 1 if zone mid is within
                                             # 0.25*ATR_H1 of a 25/50/
                                             # 75/00-pip gridline
               - 0.5 * (width / ATR_H1)      # narrower better
               + 0.25 * log(1 + age_bars/96) # ~1 day = 96 M5 bars

- For each thick cell: entries split into salience TERCILES (edges =
  33.3/66.7 percentiles of that cell's own distribution); report per
  tercile: N, exp_R (referee-simulated x1 trade list sliced by tag),
  lift_pp vs the same tercile's matched randoms, and Newcombe CI.

## A4 — Context slices (DESCRIPTIVE; no hour/day/year anywhere)

Slices computed per thick cell on the x1-simulated trade list (and the
matched randoms of the same entries), binning the ENTRY features below:

- `trend_align`: sign(s_tr_h1) == side, sign(s_tr_h4) == side
  -> bins {aligned, flat (tr==0), counter}.
- `h4_range_pos`: entry price position inside the rolling H4 range
  (max h / min l of last 24 H1 bars = ~4 days): position in [0,1] ->
  terciles {discount / mid / premium}, interpreted vs side.
- `atr_regime`: ATR(H1) tercile over the symbol's DESIGN distribution
  -> {low, mid, high}.
- `room_R`: distance from order_px to the nearest OPPOSING armed zone
  edge, in units of the entry's S -> bins {<1R, 1-2R, >=2R, none}.
- `chase_atr`: |order_px - triggering zone edge| / ATR(M5) ->
  terciles {near / mid / far}.

Metrics per bin: N, exp_R, PF, lift_pp vs matched randoms in the same
bin, Newcombe CI. BH correction (q=0.10) over ALL A4 bins x families.

## Runtime budget

A1: 32 evaluate calls (~30-60s each) ~ 30-40 min. A2-A4: one referee
simulate per thick cell (~6 x ~60s) + in-memory slicing ~ minutes.
Total < 3h wall clock.

## Output

`rounds/SF02/AUTOPSY.md` with all tables, total slice count, <=4 ranked
hypotheses, and the mandated verbatim sentence about DESIGN/CONFIRM.
