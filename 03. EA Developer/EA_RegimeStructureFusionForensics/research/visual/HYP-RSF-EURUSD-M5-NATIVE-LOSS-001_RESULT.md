## Cross-case findings

### Measured

1. Corrected QQE is not an empty/non-discriminating feature. Its MQL handle had
   been called with the wrong positional ABI because Pine-style input groups are
   real MQL input slots. After the fix, the native probe reads all buffers and
   produces directional states on the frozen bars.
2. Both range losses conflict with active TB direction/structure. The current
   range route permits a sweep and oscillator turn to overrule unreclaimed
   opposing structure.
3. All five trend/breakout examples can have strong multi-indicator directional
   agreement and still lose. The shared missing variable is entry location and
   evidence that the move has remaining path, not another same-bar vote.
4. The worst loss entered on the first breakout condition and stopped within one
   minute; the median breakout-long loser stopped within five minutes. Immediate
   S3 execution is especially exposed to impulse exhaustion.

### Inference to test, not a result

The credible successor mechanism is a temporal state machine:

1. context must persist before a setup is eligible;
2. MBB S1/S2/S3 arms a setup, but cannot enter on the same bar;
3. TB must later reclaim/confirm structure in the intended direction within a
   frozen expiry window;
4. QQE must re-accelerate after the arm rather than merely be on the correct side;
5. price-location/runway must be checked before entry;
6. risk and exit geometry remain unchanged in the first mechanism test so the
   entry effect is identifiable.

The seven losses are intentionally not used to choose numeric thresholds. Those
values must be preregistered from indicator semantics and validated on the full
2018-2022 development block before any untouched 2023-2025 evaluation.
