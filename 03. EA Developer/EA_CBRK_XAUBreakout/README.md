# EA_CBRK_XAUBreakout

Canonical XAUUSD M5 compression-breakout EA for `HYP-CBRK-XAUUSD-M5-002`.

The package is an identity-separated successor to the LOMX breakout sleeve. Its only market-logic correction is that weekday/session eligibility and Asian-date resolution use the most recently completed M5 signal bar (`rates[0]`) rather than the next decision-bar open. Exact research authority remains in the candidate registry and frozen preregistration; the default source stays build-only.
