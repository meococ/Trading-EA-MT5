# Public-cohort evidence plane

This directory separates discovery from performance verification.

- `PUBLIC_COHORT_FREEZE.json` is written after Deep Research pass 1 and before
  pass 2. It must contain 10-20 unique MT5/FX EA candidates and no return,
  profit-factor, win-rate, drawdown, or ranking fields.
- `PUBLIC_EVIDENCE_LEDGER.json` records one verification row for every frozen
  candidate, including all exclusions and delisted/terminated entities.
- `PUBLIC_VERIFICATION_READOUT.json` is generated by
  `validate_public_evidence.py` and is the machine verdict for this evidence
  layer.

Grade C evidence is feature-only. It is never eligible for performance
ranking. Fewer than five eligible grade A/B entities forces
`INSUFFICIENT_VERIFIED_DATA`.

Run:

```powershell
python validate_public_evidence.py `
  --freeze PUBLIC_COHORT_FREEZE.json `
  --ledger PUBLIC_EVIDENCE_LEDGER.json `
  --out PUBLIC_VERIFICATION_READOUT.json
```
