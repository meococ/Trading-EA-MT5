# EA_RegimeStructureFusionStateCensus

Zero-trade research wrapper for `HYP-RSF-EURUSD-M5-STATE-MODEL-012`.
It includes the canonical five-indicator RSF engine, rejects every trading
route at initialization and exports one state row per completed M5 bar.

It was reused without changing indicator semantics for HYP-012 through HYP-014:
EURUSD M5 state/transition and USDJPY M5 pair-native state discovery. All three
were terminal economic kills; 2023+ remained sealed. See
`04. Memory/research/20260808_FIVE_INDICATOR_NATIVE_CENSUS_CLOSEOUT.md`.

This package has no economic, optimization, validation, holdout, paper, live
or promotion authority.
