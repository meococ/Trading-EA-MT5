# Packets

Templates for coordinator ↔ worker handoff.

| File | Use |
|------|-----|
| [TASK_PACKET_TEMPLATE.md](TASK_PACKET_TEMPLATE.md) | Immutable scope for one worker |
| [MERGE_MEMO_TEMPLATE.md](MERGE_MEMO_TEMPLATE.md) | Parent merge after receipts |
| [SESSION_CLOSEOUT_TEMPLATE.md](SESSION_CLOSEOUT_TEMPLATE.md) | Chốt phiên A/B/C: docs + self-improve merge + cleanup |

Filled packets stay in this folder as `TASK_PACKET_*.md` / `MERGE_MEMO_*.md` /
`SESSION_CLOSEOUT_*.md`.
